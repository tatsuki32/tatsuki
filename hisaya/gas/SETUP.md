# GAS 版の公開手順

予約が入ると、スプレッドシートの残り部屋数が自動で減り、宿にメールが届きます。
お客様の名前・電話・メールはシートには保存されず、メールにだけ載ります。

## 1. スプレッドシートを開く

Google ドライブの「ひさ家 予約管理」を開きます。シートは4つあります。

| シート | 中身 |
|---|---|
| 空室 | 日付と残り部屋数。ここに無い日は休館日。0 は満室 |
| プラン | プラン名・食事・料金・提供期間。「表示」を × にすると隠せる |
| 設定 | 宿名・電話・通知先メール・LINE の URL・受付の状態 |
| 受付ログ | 申し込みの記録（日時・宿泊日・プラン・人数だけ。個人情報は入らない） |

## 2. コードを貼る

1. スプレッドシートのメニューで **拡張機能 → Apps Script** を開く
2. 最初からある `コード.gs` の中身を全部消して、`Code.gs` の中身を貼る
3. 左の「ファイル」の **＋ → HTML** で、名前を `Index` にして作る（`.html` は自動でつく）
4. `Index.html` の中身を全部消して、`Index.html` の中身を貼る
5. 💾 で保存する

## 3. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ**
2. 種類の歯車から **ウェブアプリ** を選ぶ
3. 次のように設定して **デプロイ**
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
4. 「アクセスを承認」→ 自分の Google アカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら、**詳細 → （安全ではないページ）に移動** → **許可**（自分で作ったスクリプトなので問題ありません）
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）が予約ページです

## 4. 試す

設定シートの「受付」は最初「テスト中」です。この状態でも本当に申し込めて、メールが届き、空室も減ります。

1. 予約ページの URL を開き、自分の名前とメールで申し込む
2. Gmail に「【予約申込】」のメールが届くことを確認
3. 空室シートの数字が 1 減ったことを確認
4. 試したら、空室シートの数字を元に戻す

## 5. 本番にする

- 設定シートの「受付」を **受付中** にする（画面上の「テスト中」の帯が消える）
- 予約の知らせを宿のメールに届けたいなら「通知先メール」に入れる
- 申し込んだ人に受付メールを送るなら「お客様への自動返信」を **する** にする
- LINE 公式アカウントがあれば「LINE予約URL」に入れる（LINE ボタンが出る）

## コードを直したとき

デプロイ → **デプロイを管理** → 鉛筆アイコン → バージョンを **新バージョン** → デプロイ。URL は変わりません。
シートの数字や設定を変えるだけなら、デプロイし直す必要はありません。

## 注意

- 送信元は、このシートの持ち主の Gmail です。無料の Google アカウントは 1 日 100 通までです。
- 無料アカウントだと、ページの上に「Google 以外のユーザーが作成したアプリ」という Google の表示が出ます。
- 宿の名前で公開するので、**宿の許可を取ってから**「受付中」にしてください。
- じゃらん・楽天で予約が入ったときは、空室シートの数字を手で減らしてください。
