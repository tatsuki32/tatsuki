# 01 朝コマンド：統括への依頼

## 1. 11番（まとめ）への連絡

`briefs/YYYY-MM-DD.md` は 01 と 11 が同じファイルに書きます。
01 は `<!-- morning -->` から `<!-- /morning -->` までだけを書き換え、ほかの部分は残します。
11 は `md.save` で全体を上書きせず、`md.append` で足してください。上書きすると、その日の朝の3件が消えます。

## 2. `CLAUDE.md` の1行

「Claude Code のコマンド」の行に、次の文を足します。

```
`/morning`（今日の3つ。`lifeos/01-morning/morning.py`）
```

## 3. 確かめてほしいこと

Claude のアプリには、同じ名前の朝のまとめのスキルがあります。
マージ後に `/morning` がこのコマンドを呼ぶかを確かめてください。別のものが動くなら、名前を変える必要があります。
