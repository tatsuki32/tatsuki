# 01 朝コマンド

## 目的

朝に `/morning` と打つと、今日やる3件だけが理由1行ずつ付いて出ます。4件以上は出しません。

## 使い方

- Claude Code で `/morning` と打ちます。
- 直接動かすときは `python3 lifeos/01-morning/morning.py` です。送らないときは `--no-send` を付けます。
- 続きの表示はここでは作りません。`/tsuzuki`（15番）か `/recap` を使います。

## 選ぶ順番

`desk/kickoff.py` の候補を、`/morning-kickoff` と同じ順番で選びます。

1. 今日が締切のもの
2. 前回の「次の一手」の先頭
3. 進行中のもの
4. 残りの先頭（`kickoff.py` の並びのまま）

足りないときだけ、残りの「次の一手」で埋めます。3件に満たない日は、水増ししません。
次の予定まで30分未満なら、1件目に「15分でできる部分だけ」と添えます。順番は変えません。

## 読むものと書くもの

| 種類 | 場所 |
| --- | --- |
| 読む | Desk の同期データ（タスク・予定・メール・Google タスク）、セッション記録の「次の一手」 |
| 読む | 各ツールの `brief.py`（`tools.brief_parts()`） |
| 書く | `briefs/YYYY-MM-DD.md` の朝の部分だけ。同じファイルのほかの部分は残します |
| 書く | `tools/01-morning/state.json`（今日送った内容の印） |
| 送る | Telegram。本人のチャットだけ。未接続なら `logs/outbox.jsonl` に控えを残します |

タスクの状態は変えません。

## 30秒の守り方

3件は同期済みのファイルから選ぶので、通信を待ちません。
ほかのツールの行と Telegram は、それぞれ8秒で打ち切ります。打ち切っても3件は出ます。

## 止め方

- 自動では動きません。打たなければ何も起きません。
- Telegram だけ止めるときは、`tools/01-morning/config.json` に `{"telegram": false}` と書きます。
- 接続先を替えるときは、`morning.py` の `gather`・`collect_parts`・`send_telegram` を差し替えます。
