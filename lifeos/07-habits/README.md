# 07 罰しない習慣

## 目的

できた日を数えるだけの習慣記録です。累計で植物が育ちます。数は記録で増えるだけで、減ることはありません。

| 累計 | 植物 |
| --- | --- |
| 0回〜 | 🌰 種 |
| 10回〜 | 🌱 芽 |
| 30回〜 | 🌸 花 |
| 100回〜 | 🌳 木 |

1日に何度送っても1回と数えます。Desk の習慣と同じ数え方です。

## 使い方

Telegram で送ります。トークンなしで試すときは `python3 lifeos/bot/cli.py "読書30分"` です。

- `筋トレした`、`読書30分`、`読書を30分しました`：その習慣に今日の1回が入ります。
- `昨日筋トレした`：昨日の分として入ります。
- `習慣: 5分歩く`：新しい習慣を足して、今日の1回を入れます。

文全体が報告の形のときだけ受けます。`筋トレしたい` や `読書30分したら連絡する` は受けません。

最初から分かる言葉は `core.py` の `STARTERS` です（筋トレ、読書、散歩など）。Desk にある習慣は、その名前で受けます。

`30分` のような長さは返事に出ますが、保存しません。Desk の習慣は日付だけを持つ形だからです。

記録先は Desk の `habits` です。間違えて入れた日は、Desk の習慣画面で日付を押すと消せます。

週の報告：

```sh
python3 lifeos/07-habits/weekly.py --preview   # 文面を見るだけ
python3 lifeos/07-habits/weekly.py             # 送る（同じ週に2回は送らない）
```

Telegram につながらない間は `logs/outbox.jsonl` に残ります。

## 止め方

`tool.json` の `status` を `stopped` にします。ボットが受けなくなり、週の報告も送りません。定期実行を入れたあとなら、`launchctl unload ~/Library/LaunchAgents/com.tatsuki.lifeos.07-weekly.plist` で止まります。

止めても Desk の習慣はそのまま使えます。記録も消えません。
