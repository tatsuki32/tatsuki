# 08 2分片付け

## 目的

片付けを2分だけ、1か所ずつ回します。どこをやるか考えずに始めるためのツールです。
点数や比較は出しません。ビフォーアフターも散らかり度も、前回から何日かも出しません。

## 使い方

| 送る言葉 | 起きること |
| --- | --- |
| `片付け` | 今日の2分の場所が1つ出る。「済」の前にもう一度送っても同じ場所が出る |
| `済` | 最後に片付けた日を今日にする |
| `片付け場所` | 次に出る順の一覧と、外した場所を出す |
| `片付け追加 机` | 場所を足す |
| `片付け追加 寝室 枕元` | 部屋つきで足す |
| `片付け外す 枕元` | 順番から外す。足し直すと最終日ごと戻る |

- 最後に片付けた日が古い場所から順に出ます。一度もやっていない場所が先です。
- 「済」を送らずに日が変わっても、何も言いません。翌日の「片付け」で選び直します。
- 最初の場所は机・キッチン・洗面所です。

Telegram がなくても試せます。試すだけなら `LIFEOS_DATA` を付けると本物のデータに触りません。

```sh
LIFEOS_DATA="$TMPDIR/try" python3 lifeos/bot/cli.py "片付け"
```

## データ

| 場所 | 中身 |
| --- | --- |
| `desk/data/lifeos/tools/08-tidy/places.json` | 場所のリストと最終日。手で直しても動く |
| `desk/data/lifeos/logs/tidy.jsonl` | 「済」の記録（日時と場所だけ） |

どちらも git に入りません。ファイルが壊れていたら上書きせず、ボットはエラーを返します。

## 止め方

`tool.json` の `status` を `stopped` にすると、ボットに読み込まれなくなります。ボットを起動し直すと効きます。
データは消えません。`blocked` か `working` に戻すと続きから使えます。ほかのツールには影響しません。

## 残っていること

Telegram のトークンがまだないので、Telegram からは使えません。手順は `tool.json` の `blockers` にあります。
