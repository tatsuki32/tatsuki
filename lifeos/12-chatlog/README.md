# 12 チャット記録

## 目的

思いついたときに1行送るだけで、支出と締切の記録を終わらせます。確認の返事は1行です。

## 使い方

| 送る文 | 記録先 | 返事の例 |
| --- | --- | --- |
| `ランチ 3万ドン` | `logs/expenses.jsonl` と `logs/expenses.md` | `支出：ランチ 30,000ドン` |
| `明日 資料 締切` | Desk のタスク（期日付き）とカレンダー待ちの列 | `締切：資料 11/5(木) あと1日・カレンダー待ち` |
| `締切` | 読むだけ | `11/5(木) あと1日　資料`（1件1行、10件まで） |
| `読書30分` | 07番へ。07番がなければ `logs/habits-pending.jsonl` | `習慣：読書30分 を預かりました（07番が動くまで保管します）` |

記録先はすべて `LIFEOS_DATA` の中か Desk のタスクです。リポジトリには入りません。

Telegram がなくても同じことができます。

```sh
python3 lifeos/12-chatlog/chatlog.py "ランチ 3万ドン"
python3 lifeos/12-chatlog/chatlog.py --list              # 締切の一覧
python3 lifeos/12-chatlog/chatlog.py --habits            # 07番を待っている習慣の文
python3 lifeos/12-chatlog/chatlog.py --calendar-pending  # カレンダー待ちの締切
```

## 読み取りの決まり

- 通貨は `ドン` `VND` `đ` `₫` と `円` `JPY` `yen` `¥` で見分けます。`3万5千`、`1,500`、`30.000`、`50k`、`三千` も読みます。
- 単位がない数字は、ランチや家賃など支出らしい言葉があるときだけ支出にします。1万以上はドン、それ未満は円と推定し、返事に「通貨は推定」と出します。
- 収入や請求の話、金額が2つある文、質問、複数行、60字を超える文は記録しません。次のツールへ回ります。
- 締切の言葉は `締切` `〆切` `期限` `期日` `納期` などです。日付は `明日` `金曜` `来週金曜` `11/10` `3日後` `月末` などを読みます。
- 時刻がなければ、その日の 23:59 にします。
- 日付が読めない締切は、期日なしのタスクにして、そのことを返事で伝えます。`来週` だけでは日付にしません。
- 誤って記録したら、締切は Desk のタスクで直します。支出は `logs/expenses.jsonl` と `logs/expenses.md` の行を手で直します。

## カレンダー

`gcal.py` を差し替えて接続します。`LIFEOS_CALENDAR_WRITER="package.module:function"` か `set_writer(fn)` で、`fn(title, due_ms, ref)` を渡します。
書けなかった分は順番待ちに残り、次に書けるときにまとめて書きます。Desk で期日を変えても、カレンダーの予定は追いかけません。

## 止め方

`tool.json` の `status` を `stopped` にします。ボットが読み込まなくなり、文は次のツールへ回ります。
記録済みのデータはそのまま残ります。朝のブリーフィングからも外れます。
