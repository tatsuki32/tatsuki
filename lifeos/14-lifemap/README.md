# 14 人生マップ

## 目的

仕事、お金、健康、人間関係、学び、住まい・移動の6分野について、ボットが1日1問だけ聞きます。
答えを分野別のファイルに貯め、月に1回、分野をまたいだパターンを見せます。

答えなくてかまいません。答えない日があっても、催促も集計も出しません。

## 使い方

Desk の「Life OS」画面の「14 人生マップ」から使います。Telegram はなくても動きます。

- 9時から21時のランダムな時刻に、1分野について1問出ます。答えはその日のうちなら Desk で書けます。
- 書いた答えは、15分以内にその分野のファイルに入ります。オンライン版からの答えは、毎時同期のあとに入ります。
- 「パス」を押すと、何も書かずに閉じます。答えなかった問いは次の日に消えます。
- 分野のボタンを押すと、過去の答えを読めます。
- 毎月1日の9時以降に、先月のパターンを3件まで出します。何もない月は出ません。

Telegram をつなぐと、問いと気づきがそちらにも届きます。返信は2時間まで受け、「パス」と返すと閉じます。どちらかで答えれば、もう一方は閉じます。

| 置き場（`desk/data/lifeos/` の中） | 中身 |
| --- | --- |
| `life/work.md` `money.md` `health.md` `people.md` `learning.md` `home.md` | 分野別の答え |
| `life/insights/YYYY-MM.md` | その月の気づき |
| `logs/lifemap.jsonl` | いつどの問いを聞いたか（答えの本文は入れない） |
| `tools/14-lifemap/state.json` | 今日の状態 |
| `desk/data/lifemap.json`（`lifeos/` の外） | Desk に出す問い・答え・気づき。毎時同期でオンライン版にも載る |

```sh
python3 lifeos/14-lifemap/lifemap.py status           # 今日の状態
python3 lifeos/14-lifemap/lifemap.py ask              # 今すぐ聞く（これも1日1問まで）
python3 lifeos/14-lifemap/lifemap.py insight 2026-10  # その月のパターンを見る（送らない）
```

## 止め方

```sh
python3 lifeos/14-lifemap/lifemap.py pause    # 問いを止める。再開は resume
```

ツールごと止めるときは、`tool.json` の `status` を `stopped` にします。ボットも読み込まなくなります。
どちらの止め方でも、書いたファイルと過去の答えは消えません。

## 知っておくこと

- Telegram で問いが開いている2時間は、ほかのツールの合図がない文を答えとして受けます。メモのつもりの文が入ったら、ファイルを直接直します。
- 答えの本文はオンライン版の DB にも載ります。Desk の検索と自動リンクの対象にはしていません。
- 送信に失敗した日は、聞き直しません。1日1問を守るためです。
- パターンは言葉の一致で探しています。意味は読みません。もっと賢くするときは `core.insight` の `finder` を差し替えます。
- このツールはタスクを作りません。「今やること」を増やさず、気づきも3件までです。
