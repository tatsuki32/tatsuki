# 16 案件復元

## 目的

止まっている案件を、5分以内に再開できる状態に戻します。元気がない日は、白紙から始めず、Claude の下書きに反応するだけにします。

## 使い方

Claude Code で打つか、Desk のホームの「Claude に頼む」にある「案件を思い出す」「元気がない日」を押します。

```
/where 案件名
```

Drive、Gmail、Desk のタスクを読み、5行で返します。読むだけで、何も変えません。

```
📍 案件：名前（最後の動き：10/20・15日前）
✅ どこまで：…
⏳ 残り：…
👉 次の一手：…
🔎 根拠：タスク2件・Drive1件・Gmail2件／所要1分20秒
```

読めなかった情報源は5行目に「未接続」「失敗」と出ます。分からないところは「記録なし」と出します。
`/where` だけなら、止まっている案件を3件まで出します。タスクの `note` に `案件:名前` と書いてあるものが対象です。

```
/lowenergy
/lowenergy 案件名
```

案件名がなければ、Claude が Desk の候補から1つ選びます。出た下書きに、次のどれかで返します。

| 返事 | 動き |
| --- | --- |
| `OK` | 確定する（文面の保存、タスクの追加、Gmail の下書きのどれか） |
| `直す 短く` など | 直した下書きがまた出る。OK 以外の言葉はすべてこの扱い |
| `やめる` | 何もせず終わる |

メールは Gmail の下書きまでです。送るのは本人です。

Claude なしでも、Desk のタスクだけで5行を出せます。

```sh
python3 lifeos/16-where/where.py show 案件名
```

## 止め方

- `tool.json` の `status` を `stopped` にすると、`where.py` は何もしなくなります。
- コマンドごと消すなら `.claude/commands/where.md` と `lowenergy.md` を消します。Desk のボタンも消すなら `desk/index.html` の `CC` の2行と、`desk/server.py` の `CLAUDE_CMDS` の2語を消します。
- ほかのツールはこのツールを使っていないので、止めても影響しません。

## データの置き場

すべて `LIFEOS_DATA` の中で、git には入りません。

| 場所 | 中身 |
| --- | --- |
| `logs/where.jsonl` | `/where` の結果。次回の手がかりになる |
| `tools/16-where/drafts/` | `/lowenergy` の下書きと状態 |
| `tools/16-where/approved/` | OK した文面 |

## 仕組み

- `core.py`：タスクと前回の結果を集め、必ず5行に整える。
- `draft.py`：下書きの状態を持つ。OK は「いま待っている文面」に1回だけ効く。はっきりしない言葉は承認にしない。
- `connectors.py`：Drive と Gmail の読み取りの差し替え口。既定は未接続。
- コマンドの中では Claude がコネクタで読み、結果を `where.py render` に渡します。

仕様書の `tasks/` は、Life OS の決まりに合わせて Desk のタスクを読みます。
