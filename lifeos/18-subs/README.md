# 18 サブスク自作

## 目的

今払っているサブスクを請求メールから洗い出し、自作で置き換えられるかを判定します。
置き換えた自作ツールで1か月足りたら、解約を提案します。解約は本人が行います。

## 使い方

Claude Code で `/subs` を使います。ターミナルでは `python3 lifeos/18-subs/subs.py` です。

1. 範囲を決める：`subs.py scope --months 12`（`--exclude-sender`、`--keyword`、`--platform-sender` は何度でも付けられます）
2. 洗い出す：`/subs 洗い出し`。範囲が決まるまで、メールは読みません
3. 一覧を見る：`subs.py list`。違っていれば `subs.py edit 名前 --amount 900`
4. 判定する：`/subs 判定`。表は `subs.py table` でも出ます
5. 決める：`subs.py decide 名前 replace --purpose "用途"`。09番に渡す `/newtool` の1行が出ます。用途にサービス名は書きません（公開リポジトリに残るため）
6. 使い始める：`subs.py start 名前 自作ツール名`。使った日に `subs.py used 名前`
7. 1か月たったら：`subs.py check`。条件を満たすと Desk のタスクに解約の提案が入ります
8. 解約したら：`subs.py cancelled 名前`。やめるなら `subs.py keep-paying 名前`

メールなしでも `subs.py add 名前 金額 --interval monthly` で手入力して使えます。

## 判定の決まり

- 難易度は用途で決まります。用途が分からないものは「未判定」のまま、推測で埋めません。
- 節約額は月額から自作の運用費（`--run-cost`）を引いた額です。為替は換算せず、通貨ごとに出します。
- 配信やモデルのように中身を自作できないものは「不可」です。

## 「1か月使えた」の決まり

次のどちらかで、開始から1か月以上たっているときです。仕様に数字がないので仮に決めました。

- 使った日が4日以上あり、最後に使ったのが14日以内
- 本人が `subs.py confirm 名前` で足りたと答えた

記録が足りないときは、提案せずに本人に聞きます。解約の提案は同時に3件までです。

## 洗い出しの決まり

- 残すのはサービス名・金額・日付・メールの番号だけです。件名と本文は残しません。
- 返金と支払い失敗は数えません。同じ日で同じ金額の通知は1回と数えます。
- 間隔が分からないものと、最後の請求から間が空いたものは、月の合計に入れません。
- 決済代行からの通知は、サービス名が分かるものだけを入れます。

## 戻せない操作

解約の機能はありません。`cancelled` は本人が解約したことの記録です。
`cancelled`・`keep-paying`・`remove` は、本人の確認がないと動きません。Gmail は読むだけで、下書きも送信もしません。

## 止め方

`tool.json` の `status` を `stopped` にすると、朝のブリーフィングに出なくなります。
定期実行はないので、`/subs` を打たなければ何も動きません。
データは `desk/data/lifeos/tools/18-subs/` にあります。Desk に入った提案タスクは Desk で閉じられます。

## ファイル

- `core.py`：一覧・判定・試用・提案
- `mail.py`：メールとの接続。`fetch` を差し替えられます
- `subs.py`：コマンド
- `brief.py`：朝のブリーフィングに混ぜる行（3行まで。読むだけ）
