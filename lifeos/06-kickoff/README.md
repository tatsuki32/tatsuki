# 06 初動丸投げ

## 目的

止まっている作業の最初の一歩を、Claude が実際にやります。
そのあと「次にあなたがやる5分の作業」を1つだけ出します。

## 使い方

1. Claude Code で `/kickoff 作業名` と打ちます。
2. Claude が一歩だけやります（下書きの1段落、雛形、環境の準備など）。
3. できたものの場所と、次の5分の作業が1つ出ます。

作業名を付けずに `/kickoff` と打つと、いちばん長く止まっているタスクを聞いてきます。
Desk では「Claude に頼む」の「初動を任せる」からも呼べます（検索欄で `/kickoff` でも出ます）。
朝のブリーフィングには、7日以上止まっているタスクが3件まで出ます。

## 決まりごと

- 止まっているとは：未着手か進行中で、7日以上変更がないタスクです。
- 提案に出さないもの：毎日のタスク、予定から来たタスク、Life OS が本人に頼んだ作業です。
- 記録の条件：今回作った空でないファイルと、1行の次の作業がそろったときだけです。
- メモの扱い：タスクのメモに最新の1回分を足します。本人のメモは消しません。
- 進行中が3件あるとき：状態は変えず、メモだけ足します。
- 下書きの置き場：`LIFEOS_DATA/tools/06-kickoff/work/` です。git には入りません。
- やらないこと：送信、公開、支払い、予約、削除、上書き、push です。必要なら下書きで止まります。

## 止め方

- 1つのタスクだけ：`python3 lifeos/06-kickoff/cli.py skip <タスクのid>`（7日間、提案に出ません）
- 朝の提案だけ：`python3 lifeos/06-kickoff/cli.py suggest off`（戻すときは `on`）
- ツール全体：`tool.json` の `status` を `stopped` にします。提案も `/kickoff` も止まります。

ほかのツールはこのツールがなくても動きます。

## ファイル

| ファイル | 中身 |
| --- | --- |
| `core.py` | 止まっているタスクの判定、作業名の照合、記録の確認 |
| `brief.py` | 朝のブリーフィングに混ぜる行（読むだけ） |
| `cli.py` | `/kickoff` が呼ぶコマンド |
| `.claude/commands/kickoff.md` | Claude の手順と、やらないこと |
