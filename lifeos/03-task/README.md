# 03 一瞬メモ

## 目的
思いついたタスクをその場で Desk に入れ、次の1件だけを見て、終わったら閉じます。

## 使い方
| 操作 | 内容 |
| --- | --- |
| `/task 内容` | 追加する。`!高` `!中` `!低` で優先度、`#案件名` で案件を指定できる |
| `/next` | 次の1件を出す。タスクの状態は変えない |
| `/done` | `/next` の1件を完了にする。`/next` がまだなら、進行中が1件のときだけそれを閉じる |
| `/done 題の一部` | 1件に絞れたときだけ完了にする。絞れなければ候補を出す |
| `/save` | やったことと次の一手を保存する |
| Telegram で `task: 内容` | `/task` と同じ（`タスク:` でも可） |

指定がないとき、優先度は言葉で決めます。「至急」「今日中」「締切」などは高、「いつか」「余裕」などは低、それ以外は中です。
案件名は、過去に使った名前が題に含まれていれば付き、なければ「未分類」です。
よく使う名前は `desk/data/lifeos/tools/03-task/projects.json` に配列で書いて覚えさせられます。

## 次の1件の順番
今日締切、期限切れ、進行中、優先度の順です。同じならば `desk/kickoff.py` の順番（時間帯・締切）に従います。
メールと Google タスク由来のものも候補に入ります。`/done` は Desk の完了と同じ記録をし、Google タスク本体には直接書きません。

## 保存先
- タスク：Desk の `tasks`。優先度と案件名は `note` に書きます。
- 変更履歴：`logs/task-history.jsonl`（`python3 lifeos/03-task/cli.py history`）。
- `/save`：`logs/work.jsonl`（`kind:"save"`。項目は `did` `next` `task` `branch` `changed`）。

タスクは git に入らないので、仕様書の「git 履歴で追う」は変更履歴のログに置き換えました。
記録されるのはこのツールからの変更だけです。Desk の画面で変えた分は入りません。

## 止め方
`tool.json` の `status` を `stopped` にすると、Telegram の受け口が止まります。
コマンドも止めるときは `.claude/commands/` の `task.md` `next.md` `done.md` `save.md` を消します。入れたタスクは Desk に残ります。
