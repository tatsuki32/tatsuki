# 15 続き復元

## 目的

何日空いても、次の一手がすぐ分かるようにします。大きいタスクは、15分以内のステップに分けます。

## 使い方

- `/tsuzuki`：前回どこまで・途中のもの・次の一手を3行で出します。読むだけで、何も書きません。
- `/tsuzuki 全部`：最近5つの作業を1行ずつ出します。
- `/split タスク名`：Claude が15分以内のステップに分け、Desk のタスクに足します。もう一度動かしても重なりません。
- 作業ログ：セッションの区切りでフックが `logs/work.jsonl` に書きます。導入は `INTEGRATION.md` です。

次の一手は、次の順に探します。どの行から取ったかは、3行目の末尾に出ます。

1. 作業ログの次の一手（完了したタスクと同じ題、またはこのあとに `/split` した場合は飛ばす）
2. Desk の進行中のタスク
3. `/split` で分けた、まだ始めていないステップの先頭
4. `memory/` のセッション記録（Desk の「次は？」と同じ読み方）
5. Desk の未着手のタスク

## フックが書くもの

フックは AI を使わず、会話の記録から次のものを拾います。

- やったこと：このセッションで書いたセッション記録の「いま」、コミットの1行目、依頼文の1行目の順
- 次の一手：最後の返信の「次の一手：〜」の行、セッション記録の「次」の順
- 読むだけのセッションは書きません。前回の次の一手が残ります。
- キーらしき文字は伏せ字にします。
- 失敗してもセッションを止めません。失敗の種類は `logs/work_errors.jsonl` に残ります。

## 止め方

- フックだけ止める：`tool.json` の `status` を `stopped` にします。`/tsuzuki` はそのまま使えます。
- フックを外す：`.claude/settings.json` から `15-resume/hook.py` の行を消します。
- 全部やめる：上に加えて `.claude/commands/tsuzuki.md` と `split.md` を消します。
- 記録を消す：`logs/work.jsonl` を消します。ほかのツールには影響しません。

## 単体で試す

本物のデータに触らないよう、`LIFEOS_DATA` を付けます。

```sh
LIFEOS_DATA="$TMPDIR/try" python3 lifeos/15-resume/split.py "企画書を書く" "5分 ひな形を開く" "15分 見出しを書く"
LIFEOS_DATA="$TMPDIR/try" python3 lifeos/15-resume/tsuzuki.py
python3 -m unittest lifeos.tests.test_15_resume
```
