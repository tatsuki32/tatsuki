# 11 メモ自動連携

## 目的

メモにタグと関連メモへのリンクを付け、日・週・年でまとめます。
完了条件は、1つのメモから関連メモへ2クリック以内でたどれることです。

メモを読む画面は作りません。Desk の「ノート」をそのまま使います。「メモ連携」の画面は、動かすボタンと件数だけです。[言葉] のリンクと「このノートにリンクしているもの」は Desk の機能です。

## 使い方

Mac の Desk で「🔗 メモ連携」を開き、「今すぐ連携」を押します。毎時の同期でも動きます。オンライン版と iPhone は数を見るだけです。
同じことはコマンドでもできます。

```sh
python3 lifeos/11-notes/cli.py run             # タグ・リンク・まとめ・Desk のノートを更新する
python3 lifeos/11-notes/cli.py run --no-desk   # Desk には出さず、briefs/ だけ作る
python3 lifeos/11-notes/cli.py add "文" --kind アイデア   # メモを手で足す
python3 lifeos/11-notes/cli.py show 単語帳     # メモのタグと関連メモを見る
python3 lifeos/11-notes/cli.py summary week    # day / week / year のまとめを見る
python3 lifeos/11-notes/cli.py status          # 今の設定を見る
```

試すときは先頭に `LIFEOS_DATA="$TMPDIR/try"` を付けます。本物のメモにも Desk にも触りません。

### 入るもの

`notes/` の中のファイルを読みます。元のファイルは変えません。

| 置くもの | 扱い |
| --- | --- |
| 04番のアイデア・日記（`notes/<ID>-<番号>-<種類>.md`） | そのまま入る |
| `.md` `.txt` | 1ファイル1メモ。前書き（`kind` `at` `tags` `title`）は省略できる |
| `.jsonl` | 1行1メモ（`text` か `body`。`kind` `at` は省略できる） |
| 写真（`.jpg` `.png` など） | 写真のメモ。名前に「手書き」が入るフォルダなら手書きのメモ。文字は同じ名前の `.txt` から読む |

04番がタスク・予定・支出に分けたものは、それぞれの置き場にあるので入れません。

### タグの付き方

種類、`#タグ`、`[言葉]`、Desk のノートの題名、辞書の順です。1メモ8個までです。
自分の言葉は `tools/11-notes/tags.json` に `{"タグ": ["言葉", "言葉"]}` と書くと足せます。

### 関連メモの決まり方

珍しい言葉や同じタグを共有するメモをつなぎます。規則で判定するので費用はかかりません。間違えることはあります。
1メモにつき近いものを5件まで選び、リンクは両方のメモから出します。種類が同じだけではつなぎません。

### まとめ

| まとめ | ファイル | Desk のノート |
| --- | --- | --- |
| 毎日の要約 | `briefs/2026-11-04-memo.md` | 📅 メモの要約 2026-11-04 |
| 週の振り返り | `briefs/2026-W45-memo.md` | 📅 週の振り返り 2026-W45 |
| 年のまとめ | `briefs/2026-memo.md` | 📅 年のまとめ 2026 |

メモから抜き出して並べるだけで、文章は書き起こしません。メモのない日には作りません。
朝のブリーフィング（`briefs/2026-11-04.md`）は01番のファイルなので、別の名前にしています。

### Desk との関係

- Desk のノートは毎時同期でオンライン版にも載ります。日記も載ります。載せたくないときは `run --no-desk` を使います。
- メモの題名は自動リンクにしません（`noAuto`）。Desk のあちこちがリンクだらけにならないためです。
- Desk で直したノートは上書きしません。Desk で消したノートは戻しません。
- 元のメモを消しても、Desk のノートは自動で消しません。要らなければ Desk で消します。

## つなぐもの

### Cosense

範囲が決まるまで1ページも使いません。決めたら次の順に進めます。

1. Cosense の設定からプロジェクトを JSON で書き出す。
2. `desk/data/lifeos/tools/11-notes/cosense-export.json` に置く。
3. 範囲を指定する。

```sh
python3 lifeos/11-notes/cli.py cosense-scope all --project プロジェクト名
python3 lifeos/11-notes/cli.py cosense-scope tag:語学 prefix:読書 since:2026-01-01 --project プロジェクト名
```

複数書くと、どれかに当てはまるページが対象です。題名かタグがメモと合うと、ノートに Cosense へのリンクが出ます。
ページの本文はコピーしません。書き出しファイルの代わりに API を使うなら、`links.set_cosense_loader(関数)` で差し替えます。

### 写真の文字の読み取り

画像のパスを受け取って文字を返す関数を作り、`LIFEOS_IMAGE_READER="パッケージ.モジュール:関数"` で指定します。
1枚につき1回だけ読みます。読めなくても処理は止まりません。読めていない枚数は `run` とまとめに出ます。

## 止め方

```sh
python3 lifeos/11-notes/cli.py stop    # run が何もしなくなる。メモもノートもそのまま
python3 lifeos/11-notes/cli.py start   # また動かす
```

Desk のノートから下げるときは `unpublish` です。`--yes` がないと件数を出すだけで、何も変えません。

```sh
python3 lifeos/11-notes/cli.py unpublish --yes
```

ノートは削除扱いになり、元のメモは残ります。自分で直したノートは残ります。`start` のあと `run` で戻せます。
このツールは単体で動きます。ほかのツールはこのツールを必要としません。
