# World Desk の号の形（読む画面つき）

World Desk の号は `editions/<日付>` に置きます（`python3 desk/sync.py put editions YYYY-MM-DD <file>`）。
記事に `question` と `media` があると、ページは「一覧 → 読む画面」で表示します。なければ、今までどおりの一覧で表示します。
見本は `desk/mock/world-edition-sample.json`（中身は架空）。

## 号

| 項目 | 中身 |
|---|---|
| `date` | `YYYY-MM-DD`（ホーチミンの日付） |
| `generated_at` | `11月5日 7:35` のような表示用の文字 |
| `v` | `2` |
| `headline`・`lead` | その日の全体像。予想の問いの答えを書かない |
| `stories` | 記事の配列（下） |
| `thinktank`・`watch` | 今までと同じ |

## 記事（`stories[]`）

今までの項目（`region`・`title`・`summary`・`lens`・`sources`）は残します。古いページでも読めるようにするためです。

| 項目 | 中身 |
|---|---|
| `region` | 今までと同じ英語のキー |
| `cat` | 欄。`deals`（国同士の締結）・`corp`（企業）・`phil`（研究：哲学）・`anth`（研究：人類学） |
| `title` | 見出し。結果を書かない |
| `summary` | 1〜2文。予想の問いの答えを書かない |
| `sources` | `[{name,url}]`。`media` と同じ媒体 |
| `question` | `{text, options:[3つ], answer:0〜2, result:"答えを1行で"}`。答えが記事で確かめられる問いだけ |
| `media` | 2〜3個（下） |
| `whys` | 5個。`{q, a, src:{name,url}}`。出典がなければ `src:null`（画面に「推測」と出る） |
| `root` | 水面下の原因を1行 |
| `forecast` | これから起きることについての文。本人が確率を付けて直していく |

## 媒体または研究（`media[]`）

| 項目 | 中身 |
|---|---|
| `name` | 媒体名、または研究の短い名前 |
| `lang`・`langLabel` | 原文の言語（`en`・`ru`・`zh`・`de` など）と、その日本語名 |
| `url` | 実際に開いたページ |
| `axes` | `[[見方, 値], …]`。媒体なら 立ち位置・信頼性・中身・速さ・お金。研究なら 種類・人数・方法・査読・お金。評価がなければ値を「評価なし」にする |
| `gist` | 要点。日本語で2〜3文 |
| `full` | 詳しく。日本語の段落の配列。合わせておよそ1000字 |
| `study` | 語学用（なくてもよい）。`[{words:[[単語, 英語, 日本語, 読み]], ja:"文の日本語訳"}]`。原文の言語で新しく書いた2〜3文。記事の文は写さない |
| `stress`・`omit` | 強調していること、書いていないこと |

`study` の単語は、訳がいらないものは `["and"]` のように単語だけにします。英語の原文は英語の欄を空にして、日本語だけ入れます。
中国語は4つ目に読み（ピンイン）を入れます。

## 本人の入力（`worldlog`）

ページが `PUT /api/worldlog/<号の日付>-<記事の番号>` に保存します。定期タスクは書きません。

| 項目 | 中身 |
|---|---|
| `pick`・`why`・`pickedAt` | 選んだ番号、理由、記録した時刻 |
| `forecast` | `[{at, p, why}]`。確率（0〜100）の履歴 |
| `opinion`・`noteId` | 読んだあとの意見と、保存したノート |
| `changed`・`taskId` | `task`・`pred`・`none` と、作ったタスク |
