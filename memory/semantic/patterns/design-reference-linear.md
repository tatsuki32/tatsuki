# Desk の UI の参照先：Linear

2026-11-15 に決めた。Desk の画面の作り方を迷ったら、まずこの1社を見る。
別の会社の見た目を足さない（参照は1社だけ）。

## 借りる点（構造と操作）

- 一覧と詳細を左右に分け、選んだものをその場で開く。
- キーボードで全部動く。`/` で検索とコマンド、数字・矢印・Enter で決める。Desk の仕組みに近い。
- 行の高さをそろえ、グループは薄い見出しで区切る。
- 色は灰色の階層で作り、強い色は「今どこか・次に押すもの」だけに使う。Desk では金がこの役。
- 空の状態や完了の表示は短く、静かに出す。

## 借りない点

- 見た目の色や形を写さない。Desk の色は `:root` の値（チャコール・金）のまま。
- Linear の紫系のアクセントは使わない。
- 赤や責める表示は出さない（習慣・タスクの決定）。
- 画面の文字はアメリカ英語（決定済み）。

## 使い方

- 新しい画面やカードを作るとき、「Linear ならどう並べるか」を1つだけ見て決める。
- 迷ったら [[design-nondesigner]] の順番（近接・整列・反復・コントラスト）を先に当てる。
- 375px で横スクロールが出ないことを必ず確かめる（`.claude/rules/design-ui.md`）。
