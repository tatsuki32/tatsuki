## やったこと
- `desk/finder.py`（新規）：ページから来た場所の一覧・質問・前のやりとりを Claude API（Haiku 5.5）に渡し、一覧にある id だけを返す。キーは `lifelog.api_key()`。15秒で打ち切り。保存・ログなし。
- `desk/server.py`：`POST /api/finder`。
- `desk/index.html`：`isAsk`・`FDESC`・`finderCatalog`・`askSend`・`askView`・`askLocal`（AI なしの言葉の一致）・`wireAsk`。検索欄のキー操作（↑↓・Enter・Esc）。検索結果の「Ask Desk」ボタンと `/` 一覧の項目。
- テスト：`python3 desk/tests/test_finder.py`（偽の通信）。テスト用サーバー（4797）で本物の API を使い、日本語の質問 → Inbox Cleanup へ自動移動、複数候補の選択、続けての質問、AI なしの代わり、375px を確かめた。

## 決めたこと
- 送るのは題と画面の説明だけ。返信のタスク（送り主の名前が題に入る）と本文は送らない。
- 一覧にない id は捨てる（AI が場所を作らない）。
- 画面を足したら `FDESC` に説明を足す（足さないと名前だけで探す）。
