# 2026-11-09 Mac の持ち物に写真を出す

## ひとこと
- いま：Mac 版の持ち物（Belongings）に写真が出るようになった
- 次：型が分かったものから写真を足す（編集画面の Photo URL と Photo source page）
- 待ち：なし

## やったこと
- 写真が出ない原因：`img` の32桁 id はオンライン版の asset で、`gImg` は Mac では空を返していた。
- オンライン版の asset 43枚を `desk/data/uploads/<id>.jpg` に複製し、Mac では `/uploads/<id>.jpg` を出すようにした。
- 写真のない既製品10件は公式・販売ページの写真の URL を `img` に、出典ページを `imgSrc` に入れた（画面に「Photo: ドメイン ↗」）。
- 写真のないもの16件は `emoji` を付けた。編集画面に出典と絵文字の欄を足した。「手放したもの」の欄にも写真が出る。

## 決めたこと
- ユニクロ ストレッチドライEXショーツは販売終了で、別商品（ユニクロU）の写真しかなかったので絵文字にした。
- 型が分からないもの（Baseus ケーブル、mont-bell 速乾タオル、Nature's Way のプロテイン、ヤードム）は絵文字。
