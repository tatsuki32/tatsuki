# 2026-11-05 ページに「言葉が出てくる文」のカード

## ひとこと
- いま：言葉のページに文のカードが出る
- 次：使ってみて直す所を決める
- 待ち：なし

## やったこと
- `desk/index.html` だけを変更。ノートのページに、その言葉を含む文を1文ずつカードで出す（ニュース全号・マイナー国・ノート・メモ・タスクのメモ）。文は保存せず、開くたびに計算してデータが変わるまで使い回す。
- カードを押すと元の場所へ飛び、該当の文を3秒光らせる。カード内の別の言葉を押すとそのページが開く。
- 「出典：」の行は本文の表示と編集から外してページの下へ。保存すると本文の後ろに戻すので消えない。
- 文が2つ以上ある言葉は赤（孤立）にしない。
- 「このノートにリンクしているもの」はカードに統合した。

## 分かったこと
- 言葉の一致は自動リンクと同じ規則にした（`wordPat`・`wordRe`）。1文字の言葉と自動リンクオフのノートは [ ] の文だけ。
- 太字の `**` を空白に置き換えると本文と文字が合わず、飛んだ先で光らない。消すだけにする。実データのニュース599文・マイナー国126文はすべて本文と一致した。
- ブラウザの幅指定は viewport の指定がなく 980px になるので、375px の確認は幅375pxの iframe で行った。
- デザインの本は Drive の文字変換が p.136 までで、今回もそこまで読んだ。
