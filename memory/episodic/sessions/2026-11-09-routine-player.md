- 次：朝4:00・夜17:00 のアラームで実際に使ってみて、秒数と声を直す
- 待ち：iPhone で使うかどうか（サーバーは 127.0.0.1 だけなので今は Mac のみ）

## やったこと
- `desk/index.html`：全画面の実行画面 `#rp`（`rpOpen`・`P`。`#view` の外なので `render` に邪魔されない）。チャイム → 項目名の読み上げ（Web Speech API、項目の `lang` = en・ja・ru か文字から推定）→ 円のカウントダウン。0 を過ぎても進まず +0:30 と数え、`nag` 秒ごとに音と読み上げ。完了・スキップ・一時停止・＋1分・終了、キー操作、Wake Lock、結果画面（スコア＝完了の割合、今週の回数、残りをやる）。朝は暖色、夜は星空。
- 記録：完了はチェックリストと同じ日付 doc の印、実行は `<when>Run`、`wins` に `routine-<日付>-<when>`。設定 doc に `morningAt`・`nightAt`・`voice`・`nag`・`alarm`（編集モードのフォーム）。項目の編集に秒数と読み上げ言語を追加。
- 直した不具合：`rtLoad` の古い応答が、読み込み中に保存した印を画面から消していた → 保存時刻（`S.rtSavedAt`）より前に始まった読み込みでは `routinelog` を上書きしない。実行画面は自分の結果からその日の doc を作り直す（`rpLogNow`）。
- `desk/routine_alarm.py`：`server.py` が 4747 だけで60秒ごとに呼ぶ。開始時刻（ホーチミン）から30分以内、1日1回、実行済みなら鳴らさない。`afplay`・`say`・`open http://localhost:4747/#play/<when>`。`python3 desk/routine_alarm.py plan` で確認。
- 34項目に `sec` とアイコンを API で入れた（Routinery の書き出しの秒数。書き出しにない項目は仮の秒数）。
- 確認：別ポートの複製サーバー（データは複製）で、カウントダウン・超過・各ボタン・保存の競合・結果画面・375px の表示。
