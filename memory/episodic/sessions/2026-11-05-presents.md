# プレゼント・ノート吸収・返信待ちの WhatsApp 対応

ブランチ `desk/presents`（別セッションが同じ `index.html` を編集中だったので、worktree で作業）。

## やったこと
- メモをノートに吸収：ポップアップは今日の日付ノート（`noAuto`）に時刻つきで追記。行ごとに「タスクにする」「完了にする」。残りのメモは開いたときに移る（`movedTo`）。
- 受信箱を「プレゼント」に置き換え：`presents` コレクション、`desk/presents.py`。保管から外した。
- 返信待ち：WhatsApp の1対1を追加（`waiting_threads`）。3日で `催促：名前` のタスク。1回5件まで。

## 決めたこと
- 自分の最後の発言が締めの言葉（お礼など）や4文字未満なら、相手待ちにしない。
- Wise は種類が収益のものだけ。未確認の入金は載せない。

## ハマりどころ
- worktree から CLI を動かすと、`paths.DEFAULT_*` で本物のデータと 4747 番に書く。試すときは必ず `LIFEOS_DESK_API`・`LIFEOS_DESK_DATA`・`LIFEOS_DATA` を指定する。
- `index.html` に viewport の meta がなく、スマホ幅の検証は meta を足して行った。
