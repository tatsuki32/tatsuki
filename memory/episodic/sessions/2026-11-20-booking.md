# 2026-11-20 予約ページを tany.im と Desk へ（Today Slots の置き換え）

## ひとこと

- 次：`bash desk/book_setup.sh` → サイトを deploy → Desk で Google を接続 → 自分で予約を試す

## やったこと
- 要件定義 https://claude.ai/artifact/X9RgjUYyV1MPo3kBWL1AHg のとおりに実装。
- `desk/data/tany/site/book.js`（git の外、Mac にだけある会社サイトの Worker）：
  - `/book`・`/book/p/<鍵>`（限定リンク）・`/book/c/<鍵>`（取り消し・変更）・`/book/api/slots`・`/book/api/book`・`/book/api/c/<鍵>`。
  - Desk 用 API は `Authorization: Bearer BOOK_KEY`（`/book/api/desk/state|settings|links|bookings/<id>/cancel|google|calendars`）。
  - D1 のテーブル `book_settings`・`bookings`・`book_cells`（5分の升。同じ升は入らないので二重予約が起きない）・`book_links`。
  - Google は freeBusy と events だけ。refresh token は `TOKEN_KEY` で AES-GCM に封をして D1 に置く（go.tany.im と同じやり方）。
  - メールは Resend（`BOOK_FROM`）。確認・取り消し・変更の3種類、4言語（en・ja・ru・vi）、.ics 付き。
  - `BOOK_FAKE=1` で Google とメールが偽物になる（ローカル試験用）。
- `desk/book.py`：`pull`（5分ごと。予約を `desk/data/book/bookings.json` へ）・`push-settings`・`auth`（Google の許可を取って Worker へ渡す。Mac には残さない）・`times`（空き時間の文）。
- `desk/server.py`：`GET|PUT|POST /api/book...`。`desk/notify.py`：種類 `booking`（今すぐ）。静かな時間に入った分は朝のまとめに1行。
- `desk/index.html`：`#book`（メニューの Today、Calendar の下）。Upcoming・Rules（週の表を塗る）・Private links・Past。Home に次の予約の1行（`bkgHomeLine`）。
  - 名前の衝突に注意：Bank Accounts が `bk` を使うので、予約は `bkg` で始める。
- 試験：`.claude/launch.json` の `tany-book-worker`（8790）と `desk-book-test`（4790）。`python3 -m unittest desk.tests.test_book`。
  - ローカルで確認したこと：予約 → 完了画面 → Desk の一覧に出る、同じ枠の同時予約で片方が TAKEN、限定リンクで日曜の枠が出る、取り消しページ、通知の計画に出る。

## 決めたこと
- アドレスは `tany.im/book`（`book.tany.im` ではない）。
- 言語は現在のページと同じ4つ（露を残す）。目的の名前と長さは今のものを初期値にし、Desk で直せる。
- Google のスコープは events・freebusy に加えて calendarlist.readonly（Desk でカレンダーを選ぶため）。
