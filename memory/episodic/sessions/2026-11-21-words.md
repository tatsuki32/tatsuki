# 2026-11-21 Words（言葉の記録）と Rhizome Box の言語ページ

- `desk/words.py`：`lookups`・`cards` から言語ごとの数・30日の棒・単語帳を毎回計算。Reader で押した言葉も `lookups` に残すようにした（`via: reader`）。
- Learned は AnkiConnect の `prop:ivl>=21`（読むだけ）。Anki が開いていないと数えられない。
- Rhizome Box の Worker に `PUT /_/api/desk/words`（`WORDS_KEY`）。「〜 words」のページの印の行より下だけを書く。上の本人の文は残る。
- 公開の絞り込み：検索だけで見た語は出さない（名前や漢字だけの日本語が混ざるため）。漢字だけの検索語は中国語と推定しない。
- ハマりどころ：`words.py` が `anki`・`cards` を先に import すると、それぞれの試験の設定（環境変数）より前に読まれて試験が壊れる。関数の中で import する。
- Hiragino はキリル文字を全角幅で描く。`lang` を付けて system-ui を先にした。
- 残り：Worker の deploy と `bash desk/words_setup.sh`（本人の確認後）、Anki を開いた状態での Learned の実数の確認。

## 追記：公開は覚えた語だけ・言語ごと・下に足す
- 本人の希望で、公開ページは Learned の語だけ、言語ごとに Publish／Stop。一度載せた語は変えず、新しい語は下に日付つきで足す。
- Worker は `setPub`（true で公開、false で非公開）を受ける。deploy が要る（古い Worker だと新しいページが非公開で作られる）。
