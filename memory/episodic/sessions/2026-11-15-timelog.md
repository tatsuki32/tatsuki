# 2026-11-15 時間計測（要件定義 C）

## ひとこと
- いま：タスクの時間を測れるようにした
- 次：自動化の提案（D）
- 待ち：Desk Log のカレンダーを作る

## やったこと
- `timelog`（1回の計測で doc 1つ）。Desk の「Start timer」で複数同時。画面の上の1行（`timerBar`）、止めるときに終わりの時刻を直せる。
- 集計 `#timelog`：期間・まとまり・種類・タスクごと・見積もりとの差・重なりを除いた実時間・「Is this really needed?」・記録の修正。
- Chrome 拡張 Task Desk（リポジトリの外）の `finishCurrent` が `timelog` op を積み、`sendOp` が `PUT /api/timelog/<id>`（`via: chrome`、時間は拡張が数えた `accMs`、残りは `pausedMs`）。Chrome で拡張の「再読み込み」が要る。
- `server.py` に `TASKDESK_ORIGIN`（元のフォルダの未コミットの変更と同じ行に、timelog の PUT を足した）。
- `desk/time_calendar.py` と定期タスク `desk-time-calendar`（23:30）。

## つまずき
- Google カレンダーの接続にはカレンダーを作る道具がない。「Desk Log」は本人が作る。無い夜は `status missing` を書き、Time 画面に1行出る。
- 拡張のフォルダはサンドボックスの外なので、書き込みはサンドボックスを外して行った。
