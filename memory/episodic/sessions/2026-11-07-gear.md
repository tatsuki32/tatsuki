## 決めたこと
- 重さは出典のあるものだけ数字にし、根拠（公称/実測/推定）を一緒に持つ。推定は合計の脇に「うち推定 n 点」と出す。
- 写真は Artifact の `assets`（資産置き場）に置き、`img` に資産 id を持つ。フォームの「写真を選ぶ」で iPhone から足せる（900px に縮小してから送る）。クラウドからは商品画像を取りに行けない（全ホストが遮断）ので、最新の全体写真から 43 点を切り抜いて入れた。Mac 版では `/_blob/` が無いので絵文字になる。
