# LINE の未読を返信タスクにする

## ひとこと
- いま：LINE を毎朝タスクに変える仕組みができた
- 次：未読があるときの動きを確かめる
- 待ち：朝3時の実行を見る

## やったこと
- LINE の `.edb` は暗号化なので解かず、窓のスクショを Claude API で読む方式にした。
- `desk/app/linewatch.swift`：許可を持つ部品。キー操作なし、クリックは一覧の範囲だけ。
- `desk/line_sync.py`：5分ごとの tick、1日1回。開いたトークのスクショは読めるまで queue に残す。
- 夜は `caffeinate` でスリープを止める。パスワードはどこにも持たない。

## 分かったこと
- `sips --cropOffset 0 0` は「指定なし」扱いで中央を切る。`1 1` なら左上。
- `CGEventSource.secondsSinceLastEventType(.hidSystemState)` は自分が投げたクリックも入力に数える。
- `CGWindowListCreateImage` の窓単位の撮影には、ポップアップ（別の窓）は写らない。
- LINE 26.3 の行は高さ 71pt で、一番上の行の中心は 148pt。窓の大きさでは変わらない。
- TCC の表示だけでは分からないとき、`auth_value` が 0 ならスイッチはオフ。

## 残り
- 未読があるトークでの本番確認。行の位置と、下へのスクロールの向き。
- 返信したタスクの自動完了（次フェーズ）。

## 保管の履歴
- 試しのスクショが `desk/data` の保管に入ったので、一時クローンで `filter-branch` して送り直した。木は書き換え前と同じ。
- GitHub は古いコミットを SHA 指定でしばらく返す。完全に消すには GitHub サポートへの依頼が要る。
- 個人データを新しいフォルダに置くときは、先に `backup_data.py` の `IGNORE` に足す。

## 見つけ方の変更
- 本人の案で、赤い数字 → 緑の丸 → 開く → 赤を見直す、の順にした。色は PNG を標準ライブラリで解いて判定する。
- 赤い数字はメッセージの数で、部屋の数ではない。
- `CGEvent` のスクロールは1行およそ 10pt。正の値が上、負の値が下。
- LINE はトークを「Unread messages below」の線の位置で開く。
- 未読は返信の要不要を問わず全部タスクにする（開くと未読の印が消えるため、判定の誤りが見えなくなる）。
