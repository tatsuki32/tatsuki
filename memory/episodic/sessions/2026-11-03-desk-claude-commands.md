## やったこと
- 要件定義（Claude Docs）→ 承認 → 実装。
- Home に「🤖 Claude に頼む」カード（予定・習慣の下）。時間帯のおすすめ1つ（12時前＝朝の着手、12〜18時＝何してたっけ、18時〜＝今日を残す）と、残り8つのボタン。🤖 ボタン・C キーも同じ一覧。
- 言葉が要るコマンド（/begin・/rsd・/learn・/sync・/knowledge・/desk-feature）は入力欄つき。入力は保存しない（/desk-feature の下書きだけ従来どおり残す）。
- 渡し方：Mac は `POST /api/claude` → server.py が一時ファイル＋`.command` を `open -a Terminal`。オンラインはコピー＋claude.ai/code を新しいタブ。失敗したら手でコピーする画面。
- 押した日を習慣 `claude-cmd`（⌨️ Claude コマンドを使う）に記録。消したら作り直さない（localStorage の印）。
- 検索欄で `/`（全角も可）→ コマンド一覧。日本語・ひらがな・英語・ショートカットで絞り込み、↑↓・Enter・Esc。設定は「通知音オン/オフ」（`desk-mute`）と「ショートカット一覧」。
