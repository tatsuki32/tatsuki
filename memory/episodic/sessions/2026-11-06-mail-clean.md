# メール整理（配信停止・受取拒否）

## ひとこと
- いま：12件を本物で止めた
- 次：7日後に接続が続くか見る
- 待ち：残りの候補は本人が選ぶ

## やったこと
- `desk/gmail_clean.py`、`GET /api/mailclean`、`POST /api/mailclean/scan|act|undo`、Desk の画面、`lifeos/tests/test_desk_mailclean.py`。
- 既存の Gmail コネクタはフィルタを作れず、Desk からも呼べないので、Gmail API を直接使う形にした。
- `desk/data/mailclean/` を保管から外した（配信停止の URL に個人の鍵が入る）。
- 本物で12件を止めた。配信停止10件、ワンクリックなし2件はフィルタのみ。フィルタは Gmail から読み返して確認。

## 決めたこと
- 配信停止とフィルタは同時。届いているメールは触らない。
- 署名が確かでないメールのリンクには送らない。送信の権限を持たない。

## ハマったこと
- Gmail は読みすぎると 429 だけでなく 403 も返す。理由の文で判定して待って再試行し、同時4本にした。
- Google アカウントの通知が候補に入った。アカウント系と応募系を「守る」に足した。
- OAuth の「アプリを公開」はホームページなどの登録なしでは押せない。テスト中のままなので、更新トークンが7日で切れる可能性がある。

## 確かめていないこと
- 止めた送信元の新しいメールが本当にゴミ箱へ入るか（次に届くまで分からない）。
- 配信停止の成功は相手の 2xx の返事だけで判断している。
- デザイン本は Drive の文字変換の範囲（p.136 まで）を全文読んだ。後半は読めていない。
