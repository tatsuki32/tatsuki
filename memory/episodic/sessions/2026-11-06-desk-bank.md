# Desk の送金先の口座

## ひとこと
- いま：口座の画面を作った
- 次：マージと再起動のあと本人が入力
- 待ち：本人のマージの判断

## やったこと
- `desk/bank.py` と `/api/bank`、画面 `#bank` を追加した。
- 保管から外す手段を2重にした。`backup_data.py` の `IGNORE` と、`desk/data/bank/.gitignore` の `*`。
- コピーはサーバーの `pbcopy` で行う。全桁をページに渡さずに済み、WKWebView のクリップボード制限も避けられる。

## 決定
- 保存は Mac だけ。古い「オンライン DB にも保存」は本人が取り下げた。
- 口座を消すときは論理削除の例外で、中身を消して id だけ残す。

## 知っておくこと
- launchd から起動した `pbcopy` は言語設定がないと日本語が化ける。`LANG` と `__CF_USER_TEXT_ENCODING` を渡す。
- 試験は `DESK_BANK_DIR` と `DESK_BANK_PBOARD=find` で、本物のデータとクリップボードに触れずに動かせる。
- 未確認：一般のクリップボードへのコピーと、Desk.app の窓での操作。
