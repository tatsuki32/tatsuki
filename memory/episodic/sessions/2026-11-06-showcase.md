# 見せる素材（2026-11-06）

- 追加：`desk/showcase.py`、`lifeos/tests/test_desk_showcase.py`（13件）。`server.py` に `GET /api/showcase`、`POST /api/showcase/open-local`。
- 決定：見るだけ。入口はツール画面と `/` 一覧。写真は一覧で出し、押すと Drive で開く。
- 一覧の読み方：`embeddedfolderview` の HTML をサーバーが読む。リンク共有のフォルダならログイン不要。ページに iframe で埋めないのは、`desk/app/main.swift` の `decidePolicyFor` が外部のナビゲーションをすべて既定のブラウザへ送るため。`<img>` は対象外なので、サムネイルは直接出せる。
- 手元のファイル：localhost で配信すると同じ窓が置き換わるので、設定の1件を `open` で開く。
- 確認：別ポートで 1200px と 375px を確認。幅 375px は iframe で測った。`index.html` に viewport の meta がなく、モバイルのエミュレーションでは 980px で組まれるため。
