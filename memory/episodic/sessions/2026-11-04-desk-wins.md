# 2026-11-04 朝のメールをタスクに一本化＋「できたこと」

- 次：Mac で使って直す

## やったこと
- `/desk-feature` の流れ：質問4つ → 要件定義（claude.ai の Docs）→ 承認 → 実装。
- 「朝のメール」画面を削除。返信が要るメール（要対応・返信案あり）はタスクのまま。参考メールはどこにも出さない。
  - 要約・やること・返信の下書き・送信（確認つき）はタスクの詳細に移した（`mailBlock` / `wireMail`）。
  - 送信 → タスク完了＋できたこと。「返信済みにする」→ 同じ。「送らない」→ タスクは「やめた」、記録なし。
  - 古い `#mail` はタスクへ。検索のメールはタスクとして出る（要約も検索対象）。
- 新しい画面「できたこと」（`#wins`）：今日・この7日・これまでの数、一行入力、終わった予定に「できた」、日ごとの一覧。
  - 保存は新コレクション `wins`（双方向同期。`server.py` / `sync.py` / `HOURLY_SYNC.md` に追加）。
  - タスクの完了は `task-<id>` で1回だけ。未着手・進行中に戻すと `deleted:true`。前から完了のタスクは最後の更新日で数える（書き込みなし）。
  - Claude の作業は `reports` の `done` から読む（`reports` の読み込みを400件に。Claudeの記録の日付選びは30件のまま）。
  - カレンダーの今日の終わった予定にも「できた」ボタン。
- ホームに「今日できたこと」の1行。「要対応メール」は「返信するメール」としてタスクへ。

## 確かめたこと
- Mac 版（ダミーデータの server.py）とオンライン版（偽の `window.claude`）を Playwright で操作。エラーなし、375px で横スクロールなし。
