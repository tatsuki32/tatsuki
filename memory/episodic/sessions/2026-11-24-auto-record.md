# Transcribe の自動録音（2026-11-24）

## ひとこと
- いま：予定の会議を自動で録る機能を main に入れた（初期値オフ）
- 次：マイクを許可し、Transcribe のスイッチを入れて本物の Meet で試す
- 待ち：Mac の音の録音（画面収録の許可）は、まだ一度も本物で使っていない

## やったこと
- `desk/transcribe/auto.py`：始める・止めるの判断。予定（リンク付き）＋マイクの使用で始め、2分で終える
- `desk/app/meetwatch.swift`：マイクを使うアプリを答える `who`（許可が要らない）と、マイクを録る `record`
- `desk/gcal_ics.py`：予定に `meet`・`mine` の印だけ足した（招待は誰でも送れるので、返事をしていない予定では始めない）
- Desk：上の1行（Stop・Discard）、Transcribe のスイッチ
- 議事録を予定につなぐ。`event.auto` は本人が選んだものと区別する（承諾していない招待のゲストにお礼の下書きを作らない）

## 決めたこと
- ブラウザの録音画面は使わない（開くと会議中に画面が切り替わる）。小さなアプリが直接書く
- 言語の初期値は Detect（いろいろな言語の会議があるため）
- Stop と Discard のあとは、同じ予定で始め直さない。自動で終わったあとの入り直しは新しい録音

## 調べて分かったこと
- macOS 14.2 以降の Core Audio は、マイクを使っているプログラムを bundle id で答える。許可は要らない
- `open -W` は、すぐ終わるアプリだと待たずに戻ることがある
- `desk/transcribe/` の変更は `pull.sh` では反映されない。8791 を止めると Desk のサーバーが1分以内に立ち上げる
