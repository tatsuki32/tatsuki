## 追記：機能を足した（同じ日）
- Scrapbox（Cosense）の公開ヘルプで記法・キー・選択の操作を確かめ、試作に入れた。
  - 選んだ文字に `[` `*` `/` `-` `!` `%` `|` `~` で囲む。選ぶとメニュー（リンク・太字・大きく・斜体・打ち消し・色4つ・Web リンク・コード・新しいページへ）
  - Shift+クリックで複数行を選び、新しいページに分ける（元のページへのリンクも付く）
  - `[名前.icon]`・`[名前.icon*3]`、ページの最初の画像がカードとアイコンの絵になる。Ctrl+I・Ctrl+T・Ctrl+矢印・Alt+矢印・元に戻す
  - 画像の貼り付けとドロップ。URL は自分のドメインの files/ の形にしておく（本番は R2 に置く想定）
  - `settings` ページの `code:style.css` が全体、自分のページの分は自分だけに効く。`code:*.html` はスクリプトなしの枠で表示
  - リンクの多さを 1〜100 の段階にして、文字の色と太さ・カード・ピースを濃くする（CSS 変数 `--h`）
  - リンク一覧（多い順・A–Z・ページのないもの）、ページ横に「New links」
- クラス名は Scrapbox に合わせた（`.line` `.deco-!` `strong.level-N` `img.image` など）。今の UserCSS がそのまま効きやすい。
- headless Chrome で操作の流れを自動で確かめた（ファイルを開くので `--allow-file-access-from-files` が要る。サンドボックスの外で動かす）。

## 追記：パズルをやめて、線でつながるグラフに（同じ日）
- 本人の指摘：パズルはきれいにはまる形だが、実際のリンクはそうではない。Obsidian や Miro のような見え方がいい。
- 関連ページを、実際のリンクを線でつなぐグラフに替え、見た目を3案にした（同じ配置の計算で見た目だけ違う）。
  - A Dots（Obsidian 風）：点と細い線。リンクが多いほど点が大きく濃い
  - B Roots（リゾーム風）：曲がった太さの違う根の線と、点から出る細いひげ。横に広がる
  - C Board（Miro 風）：カードと矢印つきのつなぎ線。リンクの向きが分かる。点の背景
- 点はドラッグで動き、背景のドラッグで移動、ホイール（ページ横では Ctrl＋ホイール）と＋−で拡大縮小、Fit で全体。押すとそのページを開く。マウスを乗せるとつながりだけを強く出す。
- 新しいリンクを書くと、点が増えて線が伸びる。「Graph」タブにノート全体のグラフ。
- 配置は表示前に計算し終えてから出す（開いた瞬間に落ち着いた形）。点の位置はページごとに覚える。
- 誤配の欄は「A stray page arrived」と「Connect it here」に変えた。

## 追記：フォント・動き・関連カード（同じ日）
- 本人の感想：点（Dots）がとてもいい。根（Roots）とボード（Board）も悪くない。フォントがばらばらでダサい、動きがカクカクする。
- フォントを IBM Plex Sans JP（コードは IBM Plex Mono）の1種類にそろえた。グラフの文字も同じ。
- グラフの動きをなめらかにした：拡大・縮小・Fit はゆっくり近づく、背景を動かして離すと少しすべって止まる、点に乗せると少し大きくなる、表示を切り替えると薄く出てくる。文字は拡大しても画面上の大きさがほぼ同じで、遠くでは消える（Obsidian と同じ）。
- 関連ページに「Cards」を足し、表示を Cards・Dots・Roots・Board の4つから選べるようにした。Cards は Scrapbox と同じく、直接のリンクのあとに共通の言葉ごとの札とそのページのカードが並ぶ。
- 画面は Scrapbox と同じ1列（本文 → つながり → New links と誤配）にした。
- headless Chrome は requestAnimationFrame が動かないので、動きの確認はテストの中だけ setTimeout に置き換えた。
