## やったこと
- Scrapbox 風のノートを自分のドメインに置く場合の費用と工数を調べた。1,500ページなら Cloudflare の無料枠（D1・Workers・R2）に収まる。難しいのは行ごとの編集の書き心地と同時編集。
- 操作できるモックアップを1枚の HTML で作り、非公開の Artifact に置いた（リポジトリには入れていない）。
  - 行ごとの編集（Enter・Tab・Alt+↑↓・`[` でリンク候補）、Scrapbox と同じ記法
  - ページごとの公開・非公開の切り替えと、外の人から見た表示（Visitor）
  - 関連ページ（直接のリンク＋2ホップ）を噛み合うパズルのピースで並べる。新しいリンクでピースがはまる
  - 誤配：つながっていない古いページを1枚だけ届け、「Fit it here」でリンクを足す
- 375px と 1280px で表示を確かめた（headless Chrome。サンドボックスの中では起動しない）。

## 決めたこと
- Scrapbox（Cosense）のコードは写さない。公開されていない他社のコードなので。記法とキー操作は同じにして、中身は一から書く。

- 仮の名前は Rhizome Box、場所は tany.im のサブドメインの予定。
