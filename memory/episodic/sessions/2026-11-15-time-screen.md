- 次：使ってみて色と並びを直す

## やったこと
- Tasks の Genre・Type の絞り込みに件数（`tFiltBar(base)`）。All (N) が先頭、多い順、0件も全部選べる。数えるのは未着手・進行中だけ（種類とジャンルは開いているタスクにしか付いていないため）。
- Time（`#timelog`）をメニューの Today の4番目へ（Home・Tasks・Replies・Time）。タイマーの行に「See all times →」。
- Toggl 風の日ごとの一覧、ジャンル別・まとまり別の色つきの棒。色は `genreColor`（ジャンル id のハッシュで10色から）と `GROUP_COLOR`。タイマーの行の点も同じ色。
- 試験は試験用サーバーで、ページの中だけに偽の記録を足した（保存はしていない）。375px と 1200px で横スクロールなし。

## つまずき
- サンドボックスの中で `git merge` をすると `.claude/launch.json` を書けずに途中で止まり、作業ツリーに main の変更が半分残った。`reset --hard` は許可されなかったので、名前つきの stash に退避してサンドボックスの外でマージし、中身が main と同じことを確かめてから stash を消した。マージは最初からサンドボックスの外で行う。
