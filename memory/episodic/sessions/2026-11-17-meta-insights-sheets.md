# クライアントの Meta インサイトをスプレッドシートへ

- クライアント2件が、Meta のビジネス設定でこちらのポートフォリオをパートナーに追加し、FB ページと IG を「インサイトだけ」で共有した。
- 最初のパートナー追加は汎用エラーで失敗した。こちらのポートフォリオの事業情報が空欄だったのが原因の候補。
- ポートフォリオにシステムユーザー `insights-reader`（Employee）を作り、共有された4件（インサイトだけ）とアプリ（アプリをテスト）を割り当てた。
- `tools/meta-insights/Code.gs`：スプレッドシートに入れる Apps Script。1クライアント＝1ファイル。毎朝6時（日本時間）に日別と投稿を書く。鍵はスクリプト プロパティだけ。
- 取れない指標は空欄にしてログへ（Meta の指標名がよく変わるため）。
