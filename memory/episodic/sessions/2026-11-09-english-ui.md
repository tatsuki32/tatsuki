# 2026-11-09 Desk をアメリカ英語にした

## ひとこと
- いま：Desk の画面とボットが英語になった
- 次：Mac で数日使って、変な訳を直す
- 待ち：なし

## やったこと
- `desk/index.html` の画面の文字をすべてアメリカ英語にした（日付は en-US、12時間表示）。main に入ったプロジェクト・持ち物の画面も英語。
- Python 側（通知、タスクの題、体・お金・道具の文、Telegram ボットの返事）を英語にした。ボットは日本語のコマンドもそのまま使え、英語のコマンドを足した（`tidy`、`nudge send 3`、`did workout` など）。
- 古いデータは日本語のまま読める。題名の前置きは両方を見分ける。
- 題名のルール：用件（topic）が日本語なら今までの日本語の題（`メール返信 〇〇について（名前）`）、英語なら `Email reply: <topic> (<name>)`。これで今あるタスクは日本語のまま、新しいタスクは英語になる（ページの `mailTitle`、`whatsapp_sync.title_of`、`line_sync.add_turn`、`02-followup/core.task_title`）。
- ツールと Life OS のカードは、記録の `_en` があればそれを出す（ページの `enOf`）。`lifeos/*/tool.json` 21件に `_en` を足した。
- 定期タスク19本の SKILL.md の先頭に「Language (changed 2026-11-09)」の段落を足した：Desk に書く文は英語。メールと連絡は原文を残して英語訳を添える。返信の下書きは相手の言語。カレンダーの予定は訳さない。今あるタスクは改名しない。
- サーバーと Telegram ボットを再起動し、アプリを作り直した。

## 決めたこと
- 会話・リポジトリの文書・コミットの1行目は日本語のまま。画面だけ英語。
- `*_ja` の欄は名前を変えず、中身を英語にする（データの形を変えないため）。
