# 2026-11-15 Routine アプリに目標（Goals）を足す

## ひとこと
- いま：ルーティンとは別の「Goals」（毎日・毎週・毎月、回数の目標）をアプリに入れて公開した。最初の目標はシャワー（13:00 にリマインド）
- 次：使ってみて、項目と時刻を本人が直す
- 待ち：なし

## やったこと
- `routine/public/index.html`：ホームの最初のルーティンの下に小さな Goals カード（期間ごとに分けて、＋−と回数、達成で緑・音・紙吹雪）。`#goals` で追加・変更・削除・並べ替え（最大10個）。項目は絵文字・内容・頻度・回数・リマインド時刻・軽い版の文。
- データ：`routines` の doc で `kind:"goal"`・`when:""`（ルーティンの一覧と Desk のチェックには出ない）。回数は日付 doc の `goals:{id:n}`、週（月曜から）と月は日を足す。−はその期間で一番新しい1回を戻す。
- 同期（`routine/functions/api/sync.js`）：日付 doc の `goals` は足し合わせず、新しい doc の値を使う（減らせるので）。
- Mac（`desk/routine_alarm.py`）：リマインド時刻から30分以内、達成していなければ通知と読み上げ。1日1回（状態ファイルの `g:<id>`）。静かな時間（22:00〜7:00）は通知だけ。
- 確認：スマホ幅で追加・＋−・達成・週の合計・−で前日を戻す。Mac 側は未達成のときだけ出ることを試した。
- 本人の要件から最初の目標を入れた（`g-shower`、毎日1回、13:00、軽い版あり）。

## 決めたこと
- 目標は少なく（上限10個）。できなかった日も赤やマイナスは出さない。
