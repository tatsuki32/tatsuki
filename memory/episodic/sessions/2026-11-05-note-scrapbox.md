# 2026-11-05 ノートに Scrapbox の基本機能

## ひとこと
- いま：押した行をそのまま書ける
- 次：使ってみて直す所を決める
- 待ち：なし

## やったこと
- 記法：`[* 太字]`、`[** 大きい]`、`[/ 斜体]`、`[- 打消し]`、`[タイトル URL]`（順番はどちらでも）、画像、リンク付き画像、PDF、`[名前.icon]`、`[名前 icon]`、`#タグ`、バッククォート、字下げ、`>`、`$`、`code:`、`table:`、`html:`。
- キー：選択して `[` `*` `/` `-`、Tab、Ctrl か Option と上下、Ctrl+T、Ctrl+I。
- 画像と PDF：貼り付け、ドラッグ、ファイル選択で `desk/data/uploads/` に置く（`POST /api/uploads`、`GET /uploads/<名前>`）。1個20MB、中身の先頭で種類を確かめる。SVG は入れない。
- 設定：ページ `settings` の `code:style.css` を `.wiki` の中に入れ子で効かせる。「CSS を切る」は端末に覚える。

- 本文は押した行だけが入力欄になる形に作り直した（`S.ed`、`edGo`、`edKey`）。Enter で分割、Tab で字下げと「・」、行頭の Backspace で字下げ解除と結合、上下左右で行を移動。0.5秒後に保存する。
- ノートのページに「＋ 新しいノート」と「ファイルを置く」を足した。「編集」は「全文を編集」に変えて残した。

## 分かったこと
- 編集が途中で戻ったのは、30秒ごとと窓に戻ったときの読み直し（`loadApiMemos`）が `render` を呼び、入力欄ごと描き直していたから。編集中は `render` を止めた。
- サンドボックス内では、`.claude/` を含む作業ツリーを作れず、ローカルのポートも開けない。作業ツリーは `.claude/` を除いた状態で作り、確認用サーバーは許可を得て外で動かした。コミットは対象を名前で選ぶ。
- 画面にフォーカスがないとブラウザの blur が起きない。外を押して保存する確認は、JavaScript ではなく実際のクリックで行う。
- `tatsuki` というページを作ると、ロゴの文字までリンクになるので `data-noauto` で止めた。
- デザインの本は Drive の文字変換が p.136 までで、今回もそこまで。後半はまとめで補った。
