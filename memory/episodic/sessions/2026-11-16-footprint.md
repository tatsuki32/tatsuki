## 分かったこと
- Claude のトークンの大半はキャッシュ読み出し。重みの付け方で AI の数字は桁で変わるので、料金の比を代わりに使い、幅を広く出す。
- 食事の品目は「pork soy broth 500ml」のように料理名に食材名が入る。ソース・スープは除き、「with」の具は1/4 にした。
- Desk の CSS に全体の `.col` があるので、画面の部品のクラス名は `fp` などの接頭辞を付ける。
- `index.html` には viewport の meta がない（Mac 専用）。375px の確認は meta を足して測った。
