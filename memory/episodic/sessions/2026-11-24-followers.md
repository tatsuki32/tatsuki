## やったこと

## 決めたこと
- 画面の自動読み取りと非公開 API は使わない（規約違反とアカウント停止のリスク）。
- 期間の短い書き出しは「外した人」と数えない。同じフォロー時刻の入れ替わりは ID の変更。
- 写真のタグ付けだけ数える（キャプションの @ は webhook が要る）。
- 販売はファイル分析版（審査不要の見込み）→ 接続版（審査と事業確認）の順。

## 本物の API で分かったこと
- Worker は公開済み。プロフィールと投稿一覧は読めた。1回の読み取りでの使用率は 1% 以下。
- コメントは名前なしで返る → `instagram_manage_comments` が要る。8件続けて名前がなければ許可不足と見て止め、許可のあとに読み直す。
- タグ付け・集計・ID 検索は (#10) 許可なし → 許可2つの追加待ち。
- DM の一覧は「役割のない人との会話が多すぎる」で時間切れ（code -2）。`instagram_manage_messages` の Advanced Access（審査）が要る。会話ごとに分けて読んでも同じ。返信画面の DM 取り込みも同じアカウントで失敗している。

- 許可2つを足してつなぎ直し済み（3つの Instagram と2ページはそのまま）。コメント・タグ・集計・ID 検索が読めた。
- 計測：1回目の読み取りは85回・1%以下。プロフィール確認は50件で20%（1件0.4%、1時間に約250回まで）、約2.6分。費用は0。50件のうち詳しく見えたのは13件（公開プロアカウント）、残り37件は個人アカウントなどで出ない。
- プロフィール確認とアカウントの読み取りは別の上限。上限の推定は、その上限を報告した呼び出しだけで計算するように直した。

- 本物の書き出し（Followers and following だけ・All time・JSON、依頼から5分以内に完成、0.5MB）を取り込んだ。フォロワー全員にフォロー日が入り、API の数との差は1人。フォロー中は書き出しの方が43人多い（理由は未確認）。一覧に API は使わない。
- 本人の希望：ID だけでよい。全員のプロフィール確認は動かさない。
