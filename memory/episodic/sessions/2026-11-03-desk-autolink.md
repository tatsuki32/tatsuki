# 2026-11-03 Desk 全体の文字をリンクにする

## ひとこと
- いま：どの文字でも選んでリンクにできる
- 次：iPhone で長押しを試して直す
- 待ち：main へのマージ

## やったこと
- `/desk-feature` の流れで要件定義（claude.ai の Docs）→ 承認 → 実装。
- ノートのタイトルが画面のどこに出ても自動でリンク（`autoLinkStart`、MutationObserver で変わった所だけ調べる）。データは書き換えない。
- どの文字を選んでも「リンクにする」（ノートだけ作る）。ノートがある言葉は「ノートを開く」。ノート・メモは今どおり [ ] を書き込む。
- ボタン・リンクの文字も選べる（`user-select:text`）。ドラッグで選んだときはボタンを押さない。タスクカードはタイトルからドラッグすると文字選択、下の部分を持つと移動。
- ボタンの中のリンクを押すとノート。左メニュー・下のタブ・「📒 ノート」の戻りリンクは画面切り替えを優先。
- ノートに「自動リンク：オン／オフ」（`notes` に `noAuto:true`）。

## 決めたこと
- 1文字の言葉は自動リンクしない。英字は単語の途中で当てない（後読みが使えない古い Safari では単語の区切りなしで動く）。
- ノート一覧のカードと、ノート自身のタイトルはリンクにしない。
- 選択メニューのボタンから絵文字を外した（ボタンに絵文字を付けない決まり）。

## 中断した場所
- Playwright で 1200px・375px を確認済み（ノート500件で1回 0.03秒以内、横スクロールなし）。iPhone 実機の長押し選択は未確認。

## 次の一手
- iPhone の Safari で、タスク名などボタンの文字を長押しで選べるか試す。選べなければ代わりの操作を考える。
