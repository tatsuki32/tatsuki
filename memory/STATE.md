## 決定済みの事項
- UI/UX を作るときは毎回、本を全文読んでから（`.claude/rules/design-ui.md`）。Drive の文字変換は p.136 まで。後半は Tatsuki のまとめで補っている。
- Desk の見た目：文字 12/14/16/20/28px・太さ 400/700・余白 4/8/16/24/40px。金は今いる場所・焦点・主ボタン・外部リンクだけ。ボタンに絵文字を付けない。
- 機能追加は `/desk-feature` の流れ（質問 → 要件定義 → 承認 → 実装）。質問はすべて日本語で聞く。
- Claude Code 用の機能（コマンド・ルール・フック）はこのリポジトリに置く（`.claude/`、`memory/`）。
- ノートのタイトルは Desk のどこでも自動でリンクになる（1文字は除く。ノートの「自動リンク：オフ」で止める）。
- Desk のリンクの色は Scrapbox 式：青＝つながっている（中身のあるノートがある or 2か所以上で使用）、赤＝孤立。外部リンクは金色。
- URL が変わるツールは `tools` に `urlEditable:true`。✏️ はオンライン版だけ。
- 習慣（`habits`）は連続記録を持たない。できた日の配列 `done` だけ。赤・リセット・責める表示は出さない。
- 「今日の3つ」と /morning-kickoff は同じ順番（今日締切 → 期限切れ → 進行中 → 時間帯に合うもの）。12時（ホーチミン）で集中／事務を切り替え。
