# memory/ — Claude の外付けメモリ

作業を中断しても「何してたっけ？」にファイルを根拠に答えるための置き場所。書くのは Claude、Tatsuki は読むだけでよい（直してもよい）。

**このリポジトリは公開（public）です。** ここには作業の技術的な中身だけを書く。
書かないもの：メール本文・予定の中身・メモやノートの本文・健康や体調のこと・経歴・実名・メールアドレス・パスワード・APIキー・ツールのURL（トンネルURLなど）。

## 構成

| 場所 | 中身 | いつ更新 |
| --- | --- | --- |
| `STATE.md` | 進行中の作業と状態 / 決定済みの事項 / よくあるハマりどころ（40行まで。CLAUDE.md から毎回読まれる） | 作業の区切りごと |
| `episodic/sessions/YYYY-MM-DD-話題.md` | 1セッション1ファイル。やったこと・決めたこと・中断した場所・次の一手 | セッションごと |
| `semantic/patterns/話題.md` | 繰り返し使える知識（手順・注意点） | 同じことを2回調べたとき |

## セッション記録の雛形

```markdown
# YYYY-MM-DD 話題

## ひとこと
- いま：{何が終わって、どこにいるか。20字くらい。専門用語・ファイル名・PR番号は使わない}
- 次：{次にやる1つ。20字くらい}
- 待ち：{Tatsuki がやること（なければこの行は書かない）}

## やったこと
- …（コミット短縮ハッシュがあれば添える）

## 決めたこと
- …（理由を1行で）

## 中断した場所
- …（どのファイルのどこまで / 何待ちか）

## 次の一手
- …（最初にやる1つ）
```

## ひとこと（Desk の「🧭 次は？」に出る）
- Tatsuki が一目で分かる言葉で書く。専門用語・ファイル名・ブランチ名・PR番号・コマンドは書かない。
- 例：「いま：Desk の新機能を全部入れ終わった」「次：Mac で実際に使ってみる」「待ち：リポジトリを非公開にする」

## 「何してたっけ？」への答え方
`STATE.md` と、新しいセッション記録3件を読み、「現状・直前の決定・次の一手」を5行以内で。根拠のファイル名を添える。
