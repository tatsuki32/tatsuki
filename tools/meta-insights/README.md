# Meta インサイトのスプレッドシート

クライアントの Facebook ページと Instagram の数字を、毎朝 Google スプレッドシートに書く Apps Script。
1つのスプレッドシートに、同じ会社のアカウント（FB ページ＋IG の組）をいくつでも入れられる。読むだけで、投稿や設定の変更はしない。

## しくみ
- クライアントは Meta のビジネス設定で、こちらのビジネスポートフォリオを「パートナー」に追加し、ページと Instagram の「インサイト」だけを共有する。
- こちらのポートフォリオのシステムユーザー（Employee）に、共有されたページ・Instagram（インサイトだけ）とアプリ（アプリをテスト）を割り当てる。
- システムユーザーの鍵は、スプレッドシートのスクリプト プロパティ `META_TOKEN` にだけ置く。シート・コード・このリポジトリには書かない。
- Facebook ページのインサイトはページの鍵が要るので、毎回システムユーザーの鍵から取り出す（保存しない）。

## シート
| シート | 中身 |
|---|---|
| 概要 | アカウントごとに直近7日・前の7日・増減・直近28日（数式）、Instagram の投稿の上位5件 |
| アカウント | 名前・FB ページ ID・IG ID（1行に1組。ID の列は文字の書式） |
| IG_日別 / FB_日別 | 1日×1アカウントで1行。日付とアカウントで上書きする。毎朝、直近3日を取り直す |
| IG_投稿 / FB_投稿 | アカウントごとに新しい順に50件。毎朝書き直す（読めなかったアカウントは前の行を残す） |
| 設定 | 指標の一覧など（変えられる） |
| ログ | 取れなかった指標など（500行まで） |

取れない指標（Meta が廃止した・投稿の種類で使えない）は空欄にして、ログに1回だけ残す。前に取れた値は消さない。

## 新しい会社を足す
1. 新しいスプレッドシートを作る →「拡張機能」→「Apps Script」→ `Code.gs` を貼って保存
2. スプレッドシートを開き直し、メニュー「インサイト」→ ① 初期設定
3. 「アカウント」に名前・ページ ID・Instagram ID を入れる（ビジネス設定のページと Instagram アカウントの画面にある ID）
4. ② 鍵を設定 → 「接続を確かめる」→ ③ 過去30日を取り込む → ④ 毎朝の自動取得をオン
5. システムユーザーに、そのページと Instagram を割り当てる（インサイトだけ）。鍵は作り直さなくてよい

同じ会社のアカウントを足すときは「アカウント」に1行足し、メニューの「概要を作り直す」を押す。

## 鍵の作り方（本人が行う）
ビジネス設定 → システムユーザー → `insights-reader` →「トークンを生成」→ アプリ「Tatsuki Post Studio」→ 期限「1回限り」（英語の画面では Never。期限切れにならない）→ 権限：
`instagram_basic`・`instagram_manage_insights`・`pages_show_list`・`pages_read_engagement`・`read_insights`・`business_management`
一覧に出ない権限は、アプリのダッシュボードのユースケースで先に足す。

## 注意
- クライアントにシートを渡すときは「閲覧者」で共有する（編集者はスクリプトの鍵を見られる）。
- ストーリーの数字は24時間で消えるので、このスクリプトでは取れない。
- 指標の名前は Meta がよく変える。空欄が続いたら「ログ」を見て「設定」の指標を直す。
