# /morning-kickoff（朝の着手）

目的：起動から2分以内に作業に入れるようにする。**選ぶのは Claude、始めるかどうかは Tatsuki。** 責めない・急かさない。

## 1. 読む（探し回らない）

`python3 desk/kickoff.py` を1回だけ実行する。出力（JSON）に全部入っている：
`now`（ホーチミン時間）・`mode`（12時前＝集中 / 以降＝事務）・`events`（今日の予定）・`nextEvent` と `freeMinutes`（次の予定まで何分）・`short`（30分未満なら true）・`nextSteps`（memory/ の前日の「次の一手」）・`tasks`（未着手と進行中。並び替え済み）・`dataAgeHours`（同期データの古さ）。

あわせて `memory/STATE.md` を読む（CLAUDE.md で読み込み済みならそれでよい）。

## 2. 選ぶ（最初の1つ）

上から順に当てはめ、最初に当たったものにする：
1. `dueToday: true`（今日が締切で、まだ時間がある）
2. `nextSteps` の先頭（前日の「次の一手」）。`tasks` に同じものがあればそのタスクとして扱う
3. `status: "doing"`（進行中）
4. それ以外の `tasks` の先頭（`mode` と `kind` が合うものが先に並んでいる）

- `short: true` のときは、重い作業ではなく15分で終わるもの（返信1通、確認1つ、雛形づくり）を選ぶか、選んだタスクの「15分でできる部分」だけを切り出す。
- 期限切れ（`overdue: true`）は責める言い方をしない。「今日片づけると楽になるもの」として扱う。

## 3. 開く

選んだタスクの関連資料を読む（編集はしない）：
- このリポジトリの作業なら、タスクのメモ・`memory/` の該当セッション記録・関係するファイル（Grep で場所を特定してから Read）。
- メール由来なら件名と差出人だけ使う。本文を読みに行かない。
- 作りたい機能リストのタスクなら、メモの内容と関係する既存ファイル。

## 4. 提案して止まる

次の形で10行以内に出す（画面に出すだけ。予定・メールの中身をファイルに書かない）：

```
☀️ {日付}（{曜日}）{時刻} — {集中|事務}の時間（次の予定まで {X時間Y分} / 予定なし）

👉 最初の1つ：{タスク名}
   理由：{今日が締切 / 昨日の「次の一手」/ 進行中 / …}
⏱ まず5分：{具体的な最初の一歩。動詞で始める}

開いたもの：{読んだファイル名}
今日の予定 {n}件・締切 {n}件・要対応メール {n}件

→ 「始める」「別の」「今日の一覧」
```

- `dataAgeHours` のどれかが3時間を超えていたら「同期が止まっているかもしれません（{ファイル名} が{X}時間前）」と1行足す。
- データが空なら「今日はタスクが見つかりませんでした」とし、`nextSteps` か STATE の進行中の作業から選ぶ。

## 5. 返事を受けて

- **始める**：`python3 desk/kickoff.py start <タスクのid>` で Desk のタスクを「進行中」にし、「まず5分」の作業にそのまま入る。`nextSteps` だけでタスクがない場合は、状態の更新はせずに作業に入る。
- **別の**：今の候補を除いて、2. の順で次の1つを同じ形で出す。
- **今日の一覧**：予定（時刻とタイトル）と、タスク上位5件（締切つき）を短く並べ、もう一度「どれから？」と聞く。
