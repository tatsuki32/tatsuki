# /knowledge（必要な知識だけ読む）

トピック：`$ARGUMENTS`

- 空のとき：`memory/semantic/patterns/*.md` の一覧を、ファイル名と1行目の見出しで並べるだけ（中身は読まない）。
- トピックがあるとき：ファイル名と見出しから合うものを選び（Grep で本文も探してよい）、**最大3ファイル**だけ Read する。読んだら「読んだもの：…」と、今の作業に効くポイントを3行以内でまとめる。
- 合うものがなければ「この話題の知識はまだありません。調べたら `memory/semantic/patterns/<話題>.md` に残します」と返す。

新しい知識を残すとき：1ファイル1話題、最初の行は `# 話題`、手順は番号つき、40行まで。個人データは書かない。
