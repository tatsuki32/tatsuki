# /split タスク名

分けるタスク：`$ARGUMENTS`（空なら「どのタスクを分けますか？」とだけ聞く）

1. 分け方を考える。
   - 1ステップは15分以内。動詞で終わる、具体的な動作にする。
   - 最初のステップは5分以内で、考えなくても始められるものにする。
   - 全部で12個まで。多いなら、先の部分は「残りを分ける」を最後の1ステップにする。
   - お金・送信・削除など戻せない動作は、「確認する」と「本人が実行する」を別のステップにする。Claude が実行するステップにしない。
2. 保存する。引数は1つずつシングルクォートで囲む。文字の中のシングルクォートは取り除く。

   ```
   python3 lifeos/15-resume/split.py 'タスク名' '5分 〇〇を開く' '15分 〇〇を書く'
   ```

3. スクリプトの出力をそのまま出す。ステップを全部は並べない（今やることは少なく見せる）。
4. 「保存していません」と出たら、その理由どおりに分け直してもう一度保存する。

親タスクは完了にしない。全部終わったかどうかは本人が決める。
