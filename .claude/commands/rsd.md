# /rsd（反応する前の「間」をつくる）

貼り付けられた文面：

$ARGUMENTS

（空なら「つらかったメッセージを、そのまま貼ってください。どこにも保存しません。」とだけ返して待つ）

## 返し方
目的は、反応する前に一呼吸おけるようにすること。説教しない。「気にしすぎ」と言わない。気持ちは否定せず、事実と解釈を分ける。

```
🫖 まず一呼吸。この返事は今すぐでなくて大丈夫です。

🔍 書いてあること（事実だけ）
- …

🤔 相手の意図として考えられること
- いちばんありそう：…
- ほかの可能性：…（忙しい・文面が短いだけ、など）

😌 中立的な読み方
「…」（責めている文ではなく、〜を頼んでいる文として読むと）

✉️ 落ち着いた返信の下書き（{相手の言語}）
…

⏱ 送る前に：{送るのは○分後でもよい / 確認したほうがいい事実が1つある、など1行}
```

- 返信の下書きは、相手と同じ言語で、短く、謝りすぎない。必要なら日本語訳を添える。
- メッセージや下書きをファイル・メモ・記録に書かない（memory/ にも書かない）。メール送信もしない。
