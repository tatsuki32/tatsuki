# 文体・トーン（毎回守る）

- 短く、はっきり。1文は40字前後まで、1段落は3文まで。結論を先に書く。
- 誇張しない：「革命的」「圧倒的」「必ず」「絶対」「誰でも簡単に」「〜するだけで」を使わない。数字は出典があるものだけ。
- AIっぽい言い回しを使わない：「いかがでしたか」「〜と言えるでしょう」「〜することが重要です」の連発、「さまざまな」「多岐にわたる」「深掘り」の多用、「まとめると」で始まる締め。
- です・ます調とだ・である調を1つの文章の中で混ぜない。
- 絵文字・感嘆符は発信用の文章では使いすぎない（見出しに1つまで）。
- 画面に出す文字はアメリカ英語（2026-11-09 から。ノート・メモの本文はそのまま）。会話と文書は日本語のまま。Claude が Desk に書くもの（タスクの題と詳細、`clear`、助言、号、日報）も英語。
