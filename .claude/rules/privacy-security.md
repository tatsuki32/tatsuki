# プライバシー・セキュリティ（毎回守る）

- **リポジトリに入れないもの**：メール本文、予定の中身、メモ・ノートの本文、経歴、健康や体調のこと、実名（本人・家族・相手）、個人メールアドレス、電話番号、住所・位置情報、パスワード、APIキー・トークン、ツールのURL（トンネルURL・ログイン画面など）。
- 個人データは `desk/data/`（`.gitignore` 済み）か Artifact DB に置く。memory/ には技術的な中身だけ。
- 秘密情報をチャットに貼られたら、使い終わったら残さない。ファイルに書いたら、コミット前に消す。
- メール送信・投稿・公開は、送る前に必ず Tatsuki に確認する。
- コミット前フック（`.githooks/pre-commit`）が止めたら、`--no-verify` で回避せず、中身を直す。

## 公開前チェックリスト
- [ ] 実名・メールアドレス・電話・住所が入っていない
- [ ] キー・トークン・パスワード・ログインURLが入っていない
- [ ] スクリーンショットに個人情報が写っていない

## 禁止リスト
実名など、公開できない禁止語は `tools/banned-words.local.txt`（git に入れない）に1行1語で書く。フックもここを読む。
