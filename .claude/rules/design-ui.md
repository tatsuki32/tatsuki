Drive の本を探す・全文を読む・PDF から文字を取り出す、のどれもしない。

## 手順
1. `memory/semantic/patterns/design-nondesigner.md`（本から作った Desk 用ルールとチェックリスト）を必要な所だけ見る。
2. 作業の順番：**近接 → 整列 → 反復 → コントラスト**。迷ったら、まず要らない要素を消す。
3. 仕上げに 375px と 1200px で見て、横スクロールがないか・目を細めて見てまとまっているかを確かめる。
