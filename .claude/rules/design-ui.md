# UI / UX をつくるとき（毎回守る）

Tatsuki の指示：画面・ページ・アーティファクト（Desk、HTML、スライド、図など）の UI/UX を作る・変えるときは、
**毎回『ノンデザイナーズ・デザインブック 第4版』を全文読んでから** 作る。要約だけで済ませない。

## 手順（毎回）
1. 本を全文読む。
   - クラウド：Google Drive で `title contains 'ノンデザイナーズ'` を検索し、`read_file_content` で読む。
     結果はファイルに保存されるので、`jq -r .fileContent` で取り出して最後まで順番に読む（途中で止めない）。
   - Mac：同じ PDF が手元にあれば `pdftotext` で全文を取り出して読んでもよい。
   - **既知の欠け**：Drive の文字変換は p.136 で止まる（Chapter 9〜15 の文字組み・活字のコントラストが入らない）。
     PDF は 38MB で、クラウドのダウンロード上限（10MB）を超える。後半は、Tatsuki のまとめを `design-nondesigner.md` の3章に入れてある。
     後半を読める形（分割 PDF など）が Drive に置かれたら、それも全部読む。読めなかった範囲は、作業の報告で正直に伝える。
2. `memory/semantic/patterns/design-nondesigner.md`（本から作った Desk 用ルールとチェックリスト）を読む。
3. 作業の順番は本どおり：**近接 → 整列 → 反復 → コントラスト**。迷ったら、まず要らない要素を消す。
4. 仕上げに、同じファイルの「デザインレビュー用チェックリスト」15項目を1つずつ確かめる。
   375px と 1200px のスクリーンショットで、目を細めて見る。

## 注意
- 本の本文をリポジトリに入れない（このリポジトリは公開。著作物）。ルールは言い換えて書く。引用は短い語句だけ。
- Desk の決定（黒＋金、画面の文字は日本語、習慣で赤や責める表示を出さない、Scrapbox 式リンク色）は、本のルールより優先する。
