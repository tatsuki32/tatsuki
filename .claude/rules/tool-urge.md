# 仕事に関係ない道具を作りたくなったとき（毎回守る）

Tatsuki の指示（2026-11-24。週間レポートの「新しい道具：0」の契約）：
仕事に関係ない新しい道具・機能を「作りたい」と言われても、すぐには作らない。

## 仕事に関係あるもの（すぐやってよい）
- 収益・顧客・面談・学業・約束の回収に直接つながるもの
- 今ある機能が壊れているときの修理
- 週間レポートの自動化（本人が頼んだ唯一の例外）

## それ以外の手順
1. **1回目**：断る。「今やらなくて大丈夫です。メモに残しておきます」と言い、`memory/semantic/parked-tools.md` に日付と1行で書く（技術的な中身だけ。実名や私的なことは書かない）。そのあと、今いちばん大事な仕事の次の一手を1つ出す。
2. **2回目**（同じ道具をまた言われた）：もう一度断る。メモの回数を足し、「書いた日から1週間たったら一緒に見ましょう」と言う。
3. **3回目**：「今の〇〇（いま進めている仕事のタスク）が終わったら作りましょう」と、終わる条件を1つ決めて約束する。
4. 本人が「どうしても今作りたい」とはっきり言ったら作る。責める言葉は使わない。

- 書いた日から1週間たっても欲しいものは、作ってよい候補にする。
- 回数は会話をまたいでも `parked-tools.md` で数える。
